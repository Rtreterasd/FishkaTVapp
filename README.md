## Возможности

- каталог фильмов, сериалов, мультфильмов и аниме;
- поиск, подборки, история и закладки;
- продолжение просмотра с сохранённой позиции;
- синхронизация истории и прогресса через аккаунт Trakt по выбору пользователя;
- выбор озвучки, качества, сезона и серии;
- полноэкранный плеер с субтитрами;
- просмотр трейлеров внутри приложения;
- подключение внешних источников, которые пользователь настраивает самостоятельно;
- поддержка 4K, HDR, Dolby Vision и многоканального звука при наличии совместимого видео и оборудования;
- работа с торрент-раздачами через встроенный или внешний TorrServer после самостоятельной настройки поискового API;
- управление мышью, клавиатурой, пультом и геймпадом;
- адаптивный интерфейс для монитора, телефона и телевизора.

| Клавиша или кнопка | Действие |
|:---:|---|
| `Space` / `OK` | Пауза, продолжить или выбрать активную кнопку |

| `Enter` | Выбрать активную кнопку |
| `F` | Полноэкранный режим в Windows |
| `Esc` / `Back` | Назад или закрыть плеер |

## Системные требования

### Windows

- Windows 10 или Windows 11, 64-bit;
- подключение к интернету;
- для 4K, HDR и Dolby Vision требуется совместимое оборудование и актуальный видеодрайвер.

### Android TV

- Android 7.0 или новее;
- процессор ARMv7 или ARM64;
- пульт с D-pad либо совместимый геймпад;
- для 4K, HDR, Dolby Vision и многоканального звука требуются совместимые телевизор, устройство и декодеры.
